# Krakentis Sang Pemutar Arus

Kategori: 09 Laut Rangkaruna  
Elemen: Air  
Kelemahan: Api  
Tipe Serangan: Melee

MP: 35000  
Spawn Location: Perairan Dalam Rangkaruna
