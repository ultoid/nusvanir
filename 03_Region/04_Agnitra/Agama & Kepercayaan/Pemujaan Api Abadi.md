# Pemujaan Api Abadi

Bagi bangsa [[Nagarasven]] dan makhluk yang menghuni [[Agnitra]], agama bukanlah tentang entitas yang tidak terlihat di langit atau kekuatan ghaib, melainkan tentang penghormatan terhadap alam yang murni dan bergejolak.

Mereka mempraktikkan **Pemujaan Api Abadi**, di mana Gunung Mahasvara dianggap sebagai manifestasi hidup dari keagungan alam semesta, sebuah jantung berdetak yang terus-menerus memompa darah berupa magma panas ke pembuluh-pembuluh bumi. 

Dalam pemahaman mereka, peleburan logam dan pembentukan benda baru dari abu vulkanik adalah bentuk doa tertinggi. Tidak ada kuil atau pendeta; upacara spiritual mereka adalah ketika seekor naga menyemburkan api untuk menempa bijih logam mulia menjadi struktur kehidupan atau senjata, menyimbolkan siklus penghancuran dan penciptaan yang abadi. Mereka percaya bahwa selama Mahasvara menyala, kehidupan di Nusvanir akan terus terjaga keseimbangannya.
