# Pari Kematian Besi

Kategori: 09 Laut Rangkaruna  
Elemen: Baja/Air  
Kelemahan: Api  
Tipe Serangan: Melee  
HP: 55000  
MP: 15000  
Spawn Location: Perairan Dangkal Rangkaruna  

Ikan pari purba selebar alun-alun kota dengan tubuh berlapis pelat alami sekeras baja. Ekornya berbentuk seperti tombak beracun yang bisa mengiris dan menembus lantai dek kapal dalam sekali tebas.
